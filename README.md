# 🏛️ Egypt Time-Travel Tourism Website

A futuristic, immersive travel booking website for Egypt tourism. **"Ancient Egypt reborn in the future."**

![Next.js](https://img.shields.io/badge/Next.js-14-black)
![Tailwind CSS](https://img.shields.io/badge/Tailwind-3.4-blue)
![Framer Motion](https://img.shields.io/badge/Framer_Motion-11-purple)

## ✨ Features

- 🎬 **Cinematic Loading** - Hieroglyph animations, pyramid drawing effect
- 🏛️ **Immersive Homepage** - Parallax pyramids, floating particles
- 𓂀 **AI Travel Oracle** - Interactive chat assistant
- 🪲 **Mission-Style Booking** - Scarab progress indicator
- 🌐 **Multi-language** - EN, FR, DE, IT, ES support
- ⚡ **Time Gate Packages** - Europe → Egypt direct tours

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Open http://localhost:3000
```

## 📁 Project Structure

```
src/
├── app/                    # Next.js App Router
│   ├── page.js            # Homepage
│   ├── destinations/      # Destinations page
│   ├── tours/             # Tours & packages
│   └── booking/           # Booking flow
├── components/
│   ├── loading/           # Cinematic loader
│   ├── navigation/        # Header, Footer
│   ├── hero/              # Hero section, particles
│   ├── oracle/            # AI Oracle chat
│   ├── cards/             # Hologram, Tour cards
│   ├── booking/           # Booking flow, Scarab progress
│   └── ui/                # Buttons, Cursor
└── lib/
    └── data.js            # Sample tours & destinations
```
